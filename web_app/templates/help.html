Справка менеджера

К сделкам
Быстрый сценарий
  1. Новая сделка — вставьте протокол или файл (.txt, .docx, .pdf).
  2. Смотрите %, грейд лида A/B/C и бейдж эскалация.
  3. Если < 80% — откройте «Недостающие данные» и доспросите клиента.
  4. Вкладка КП → Сгенерировать → Утвердить. Клиенту только утверждённое.
  5. Отправьте: Email (основной) или Telegram (после привязки).
Бейджи на карточке

Справа в блоке «Заполнение данных».

  • LLM — разобрала модель. regex — запасной разбор, сверьте цифры. LLM + regex — смешанный.
  • Лид A / B / C — приоритет очереди, не разрешение слать КП. Порог КП по-прежнему %.
  • Эскалация — наведите курсор: причина и кому передать. Суд / юрист / угроза — не слать КП, к руководителю. Мало данных — доспросить.

Сделка без действий больше 3 дней — система напомнит. Это не штраф.

Обязательные поля (эталон)

Для генерации КП нужно ≥ {{ kp_threshold }}% (минимум 6 из 7 полей).

  • Телефон
  • Email (основной канал отправки)
  • Участок
  • Площадь дома (м²)
  • Материал стен
  • Сроки старта
  • Финансирование
  • Для клееного бруса — проект каталога (Сириус 2.0, Альба…). Без проекта КП не собрать.

Газобетон «Дом-Мастер»: стоимость ТК = площадь × {{ price_per_m2_fmt }} ₽/м². Клееный брус: смета по этапам + 5%, ставка м² не используется. Telegram и бюджет клиента для % не обязательны.

Telegram

Чтобы слать КП в Telegram:

  1. Скопируйте ссылку привязки в карточке сделки.
  2. Отправьте клиенту.
  3. Клиент открывает и жмёт Start.
  4. В карточке появится «привязан».

Рабочий стол — браузер. Бот @stroyka_KP_bot — канал доставки, не ввод сделок.
