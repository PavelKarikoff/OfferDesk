# AI-квалификатор лидов для ИЖС

**Одностраничный оффер для фриланса / резюме.**
Автор: Павел Кофф · OfferDesk · 2026

---

## Кому

Строительные компании ИЖС с отделом продаж **3–20 человек**, которые:
- теряют лиды из-за медленной реакции (норма — 15 мин, факт — часы);
- тратят 40–60 минут на подготовку одного КП вручную;
- не видят, какие поля разобраны достоверно, а какие — заглушки.

## Что

Внедряю **AI-слой поверх существующей CRM**: транскрибация звонка ->
структурированный JSON -> валидация -> эскалация -> lead scoring -> аудит.

Не заменяю CRM, не ломаю процессы. Работаю с тем, что есть.

## Результат

| Метрика | До | После |
|---|---|---|
| Время на подготовку КП | 40–60 мин | 3–5 мин |
| Время реакции на лид | часы | 15 мин |
| Конверсия в замер | базовый | +10–15% |
| Прозрачность качества | нет | precision/recall + audit_log |

**Окупаемость:** при чеке 8 млн ₽ и марже 15% — **от 1 недели до 1 месяца**.

## Что входит

- **Аудит процесса продаж** — где теряются лиды, какие поля критичны.
- **Настройка LLM-экстрактора** — структурирование транскрибации под ваш эталон.
- **Валидация и эскалация** — бизнес-правила, маршрутизация негатива и юр. рисков.
- **Lead scoring A/B/C** — приоритизация лидов для менеджеров.
- **Аудит качества** — журнал разбора, precision/recall, распределение A/B/C.
- **Интеграция** — email (SMTP) + Telegram для доставки КП.
- **Дашборд качества** — сводка по источникам (LLM / regex / merged), % эскалаций.
- **Обучение менеджеров** — 1 день + документация.

## Цена

- **Пилот на 50 звонках** — бесплатно (демонстрация на ваших данных).
- **Полное внедрение** — фикс (обсуждается по объёму).
- **Подписка** — 30–50 тыс. ₽/мес (включая OpenAI API, VPS, поддержку).

## Что НЕ входит

- Интеграция с 1С / ERP — обсуждается отдельно.
- Юридическая экспертиза КП — остаётся за клиентом.
- Замена существующей CRM — работаю поверх.
- Ценообразование — LLM не решает цену, только структурирует.

## Почему я

- **Продуктовый подход**, не «поделка на LLM». Полный цикл: pipeline -> валидация -> эскалация -> аудит.
- **Отказоустойчивость**: при недоступности LLM — regex fallback (проверено вживую, 53.3% exact etalon_score).
- **Честные метрики**: golden set из 15 кейсов, precision/recall по 8 полям, пороговый тест от регрессий.
- **Три бага, найденных тестами и смоуком** — история инженерной зрелости (см. `docs/KNOWN_ISSUES.md`).
- **Понимаю предметную область ИЖС**: эталон протокола, цена тёплого контура (75 тыс. ₽/м²), специфика клееного бруса.
