# Скринкаст для менеджеров ОП — сценарий записи

**Длительность:** 6–8 минут  
**CRM:** http://194.67.103.144:5001  
**Дата:** 13.08.2026 (релиз v1.0.0)

Не нажимайте **«Загрузить демо»** на боевой CRM: это удалит все сделки.  
Для ролика создайте **две демо-сделки** вручную (протоколы 1 и 2).

Тексты: `knowledge_base/demo_protocol_1.md` (полный) и `demo_protocol_2.md` (дыры).

---

## Подготовка (2 мин, не в кадр)

1. Браузер: окно 1440×900, масштаб 100%, без лишних вкладок.
2. Войти в CRM. Дашборд должен быть виден.
3. Скопировать в буфер текст протокола 1 (полный) и держать протокол 2 под рукой.
4. QuickTime / OBS: только окно браузера, без панели паролей.
5. Микрофон: 2 секунды тишины в начале.

## Тайминг

| Мин | Что на экране | Что сказать |
|-----|----------------|-------------|
| 0:00–0:40 | Дашборд | «После звонка не собираем КП вручную. Открываем OfferDesk: сделки, процент готовности, генерация и отправка КП. Заказчик — Дом-Мастер.» |
| 0:40–1:20 | Сделки → Новая сделка | «Создаём сделку, вставляем транскрибацию. Имя, телефон, email, площадь система заполнит сама.» |
| 1:20–2:10 | Карточка, % ≈100% | «Семь полей эталона. Порог 80% — можно КП. Здесь все поля на месте, бейдж зелёный.» |
| 2:10–3:20 | Вторая сделка, % ≈43% → Недостающие данные | «Если данных мало — кнопка КП скрыта. Открываем недостающие данные: готовые вопросы клиенту. После звонка — Редактировать, процент пересчитается.» |
| 3:20–4:50 | Вкладка КП, полная сделка | «Генерируем КП. Цена — площадь × 75 000 ₽ за м², тёплый контур. Ждём минуту. Скачиваем черновик.» |
| 4:50–5:50 | Утвердить → Email | «Клиенту только после „Утвердить“ — появится водяной знак. Основной канал — email. Telegram — если клиент привязал бота по ссылке из карточки.» |
| 5:50–6:40 | История + чек-лист | «Во вкладке История — журнал. Перед отправкой: телефон, email, площадь, утверждено, канал выбран.» |
| 6:40–7:20 | Справка / финал | «Подробности — пункт Справка в меню. Канал для менеджеров: @stroyka_KP_bot. Вопросы — администратору.» |

Если генерация КП > 90 сек — не обрывать: «Иногда до минуты-двух, это нормально. Если сеть оборвётся — можно повторить, соберётся шаблон.»

## Кадр: не показывать

- пароль на экране входа (войти до записи);
- чужие боевые сделки с реальными ФИО/телефонами — фильтр / демо-карточки;
- `.env`, SSH, админ-кнопки «Очистить» / «Загрузить демо».

## После записи

1. Сохранить файл: `docs/screenshots/screencast_managers_v1.0.0.mp4` (или диск ОП).
2. Длительность 6–8 мин, речь без «эм».
3. Отправить менеджерам ссылку **до** обучения в 16:00.
