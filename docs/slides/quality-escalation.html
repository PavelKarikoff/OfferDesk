Контроль качества · сознательное отклонение

Regex не эскалирует по confidence=0.3

Чеклист

confidence=low → escalate=true

  • LLM (source=llm): confidence < 0.6 → эскалация
  • Regex (source=regex): не эскалируем по confidence — у канала всегда 0.3

Чем заменяем

  • Для обоих каналов: etalon_score < 30 → insufficient_data
  • Мягкая эскалация: intent=qualify, escalate=true, уточнить поля
  • Падение модели → llm_failed, даже если regex собрал карточку

Это правило, а не шум: regex-fallback в 71% случаев извлекает корректные поля. Эскалировать каждую regex-сделку — снижать пропускную способность менеджера.
