# Письмо 1 — шаблон отклика «автоматизация процесса»

**ЦА:** строительные компании ИЖС с отделом продаж 3–20 человек (руководитель ОП, собственник, РОП).  
**Продукт:** OfferDesk — AI-квалификатор входящих заявок.  
**Исходный шаблон:** входящие / лиды / документы → JSON → эскалация → действие.

---

**Тема:** `Входящие заявки без ручной разборки — {компания}`
