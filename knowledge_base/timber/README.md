# КП: дома из клееного бруса

Отдельный контур коммерческого предложения — **не** путать со ставкой тёплого контура «Дом-Мастер» (газобетон, 75 000 ₽/м²).

Этот шаблон рассчитан на любую компанию, которая строит дома из **клееного бруса**.

## Как устроено

| Файл | Назначение |
|------|------------|
| [kp_template.md](kp_template.md) | Канонический Jinja-шаблон КП (структура + переменные) |
| [standards.md](standards.md) | Правила: варианты, состав сметы, входит/не входит, гарантии |
| [catalog.md](catalog.md) | Типовые проекты каталога клееного бруса |
| [example_sirius.md](example_sirius.md) | Заполненный пример: проект «Сириус 2.0», вариант «Стандарт» |
| [demo_protocol_19_08.txt](demo_protocol_19_08.txt) | Учебный протокол звонка (Дмитрий, клееный брус, 100–110 м²) |

PDF рендерится из `templates/kp_timber_template.html` (наследует `templates/base_kp.html`). Контекст собирает `utils/timber_kp.py`.

## Что подставлять в шаблон

Обязательные переменные компании (чтобы шаблон работал для любой компании контура):

- `company_name`, `company_legal`, `company_tagline`
- `phone`, `email`, `website`, `address`
- `client_name`, `current_date`, `project_name`
- `sections` — этапы сметы (позиции: кол-во, материал, работа, итог)
- `overhead_pct` — накладные (по умолчанию 5%)
- `included` / `excluded`, `warranty`, `next_steps`

Цены **не** считаются от площади × ставка. Источник — смета по этапам (ТК / каталог / выезд на участок).

## Важно для парсера

В сметах по клееному брусу строка вроде «вынос точек до 150 м» — это **дальность разбивки осей**, а не площадь дома. Площадь брать из проекта (для «Сириус 2.0» ориентир каталога ≈ 200 м²).
