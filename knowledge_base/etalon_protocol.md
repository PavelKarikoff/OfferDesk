## Обязательные поля для формирования КП

1. **Телефон** (+7 XXX XXX-XX-XX) — ОБЯЗАТЕЛЬНО
2. **Email** — ОБЯЗАТЕЛЬНО (основной канал отправки КП, наравне с телефоном)
3. **Участок** — ОБЯЗАТЕЛЬНО (наличие, размер ≥ 6 соток, расположение)
4. **Площадь дома** — ОБЯЗАТЕЛЬНО (м²)
5. **Материал стен** — ОБЯЗАТЕЛЬНО (стандарт компании: газобетон)
6. **Сроки старта** — ОБЯЗАТЕЛЬНО (месяц/сезон, год)
7. **Источник финансирования** — ОБЯЗАТЕЛЬНО (свои/ипотека/маткапитал)

## Дом из клееного бруса

Если материал стен — клееный / профилированный брус, к семи полям добавляется:

8. **Проект каталога** — ОБЯЗАТЕЛЬНО. Типовой дом из каталога клееного бруса (например «Сириус 2.0», 200 м²) или «Индивидуальный».

Без названия проекта КП по брусу не генерируем, даже если остальные поля заполнены. Ставка 75 000 ₽/м² не применяется.

## Каналы доставки КП

| Канал | Статус | Правило |
|-------|--------|---------|
| **Email** | Основной, обязательный | Без email сделку не сохраняем / не считаем комплектной для отправки КП |
| **Telegram** | Опциональный | Привязка через deep-link CRM; менеджер выбирает отправку отдельно |
| Телефон | Обязательный контакт | Для связи; КП по телефону не отправляем |

Менеджер в CRM выбирает канал вручную: **Email** или **Telegram** (не оба сразу по умолчанию).

## Необязательные / апсейл

8. **Telegram** (@username / chat_id) — НЕОБЯЗАТЕЛЬНО (доп. канал КП)
9. **Проектная документация** — ДЛЯ АПСЕЙЛА (АР/КР/ИР)
10. **Инженерные системы** — ДЛЯ АПСЕЙЛА (вода/канализация/отопление/электрика)
11. **Внутренняя отделка** — ДЛЯ АПСЕЙЛА (черновая/чистовая)

**Необязательно:** бюджет клиента (если назвал — фиксируем отдельно).  
**Автоматически:** «Стоимость ТК» = площадь × 75 000 ₽/м² (стандарт «Дом-Мастер»).
